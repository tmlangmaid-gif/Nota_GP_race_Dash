Vercel
Free — hosts only the static HTML/JS/CSS. Auto-deploys whenever I git push a frontend change.
Hostinger VPS
Your existing server — runs three Docker containers (Traefik for HTTPS, Postgres, and our backend with the headless Chromium scraper).
Natsoft
Their live-timing widget loads at http://server.natsoft.com.au:8080/LiveMeeting/<date>.<venue>. Our scraper opens it in headless Chromium and reads cars + lap times out of the rendered DOM.
Postgres
Stores users, events, drivers, all lap times, tyre stints, and event sharing. Stays on the VPS — we never reach in from the browser.

Frontend changes
Anything in frontend/ → Vercel rebuilds automatically (~30s). You just hard-refresh the browser.
Backend changes
Anything in backend/ or docker-compose.prod.yml → GitHub Actions SSHes into the VPS and runs docker compose up -d --build (~90s).
Why it's safe
The deploy SSH key is stored as a GitHub secret. Only pushes to your repo trigger the action. Any other secrets (Postgres password, Resend API key, etc.) live only on the VPS in .env.
