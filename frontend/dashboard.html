Visibility

Private events are only visible to you and people you've explicitly invited. Public events are visible (read-only) to anyone with a Race Dash account. You stay the owner either way.

Minimum lap time warning

Laps faster than this will be highlighted red — useful for flagging suspicious times. Default 1:12.000. Accepts M:SS.mmm or just seconds (e.g. 72 or 72.5).

Outlier filter (pit laps)

Charts hide laps slower than (median × this multiplier) per vehicle, so a pit-in lap doesn't flatten the rest of the y-axis. Default 2.5. Set to 0 to disable. Tables still show outliers with a ⊘ mark so you can see the data exists.
